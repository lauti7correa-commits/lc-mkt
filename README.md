# lc-mkt

Imágenes públicas de las piezas de marketing de **LocalCenter**.

Este repo existe por un motivo técnico: la API de publicación de Instagram no acepta que se le
suba el archivo — exige que la imagen esté en una **URL pública HTTPS** al momento de publicar.
GitHub Pages las sirve.

Se genera automáticamente desde el workspace de la Agencia. **No editar a mano.**

Servido en: https://lauti7correa-commits.github.io/lc-mkt/
